# LMA · Odontologia & Estética

Site institucional + sistema de gestão da Dra. Luíza Martins Albuquerque.

## Estrutura
- `index.html` — estrutura da página
- `styles.css` — todo o visual (tema rosa/dourado, claro/escuro)
- `app.js` — toda a lógica (agendamento, painel, odontograma, orçamentos, financeiro, documentos)
- `assets/` — logos e fotos

## Rodar
Abra o `index.html` no navegador. Para editar com recarregamento automático,
use a extensão **Live Server** do VS Code (botão direito no index.html → "Open with Live Server").

## Painel (demonstração)
Rodapé → "Área da equipe" → usuário `admin` / senha `admin`.
Nesta versão os dados ficam só na sessão do navegador. A versão definitiva usa Supabase.
